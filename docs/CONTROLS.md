# Controls

## Move (hull)
- Turn: `←`/`→` or `A`/`D` (gamepad: D-pad left/right)
- Forward: `↑` / `W` (gamepad: D-pad up)
- Reverse: `↓` / `S` (gamepad: D-pad down)

## Aim (turret) & fire
- Rotate turret: `J` (CCW) / `L` (CW) (gamepad: LB/RB)
- Aim to hull heading: `I` — aim to reverse: `K`
- Fire: `Space` (gamepad: south button or right stick)
- Mouse control (menu option): turret slews toward the cursor at a fixed speed; hold the left mouse button to fire

## Other
- Pan camera: `P` toggles; `T`/`G`/`F`/`H` = up/down/left/right
- Invisibility (debug): `Y`
- Pause / return to menu: `Esc` / `Enter` (gamepad: Start)
- Quit app: gamepad Start + Select

## Menu
- Navigate: arrows or `WASD` — Select: `Enter`/`Space`
